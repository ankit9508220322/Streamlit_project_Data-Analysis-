# 🚀 Streamlit Data Analysis Project

This project is a **Data Analysis application built with Streamlit**. It helps present data analysis results in a simple and interactive web interface.

## 📊 Features

- Data loading and exploration
- Data cleaning
- Exploratory Data Analysis (EDA)
- Charts and visualizations
- Startup and business data analysis
- Interactive Streamlit interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Streamlit

## 🎯 Purpose

The main purpose of this project is to turn data into **easy-to-understand charts and useful insights** through an interactive application.

## ▶️ Run the Project

```bash
python -m streamlit run Project1.py
```
